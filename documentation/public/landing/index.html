A macOS terminal for working
with coding agents

Boo is a native macOS terminal built on Ghostty. It adds workspaces, split panes, a file explorer, browser and editor tabs, and tools for running Claude Code, Codex and other agents side by side.

Workspaces and splits

Open a folder as a workspace. Each workspace has its own color, file tree and pane layout, and each pane has its own tab bar. Boo restores all of it, scrollback included, when you start it again.

  • Split right with ⌘D and down with ⇧⌘D, or drag a tab onto the edge of a pane.
  • Group tabs by color, or show them in a vertical list with each agent's state.
  • Save a layout and its commands as a recipe and open it again in one step.
  • Tear tabs off into new windows and merge them back later.

Tabs for more than terminals

A tab can also hold a browser, a code editor, an image, a markdown preview or a recording. They share the tab bar with your shells, so the dev server can sit next to its logs.

  • Open a browser tab with ⇧⌘T, or ⌘-click a URL in the terminal.
  • The editor saves automatically, can format on save and reloads when the file changes on disk. ⌘F opens find and replace.
  • Source files, scripts, dotfiles and files like LICENSE open in the editor. Binaries do not.
  • Progress reported with OSC 9;4 shows on the tab, the workspace and the Dock icon.

Files and git, local or remote

The file tree follows the active terminal. Local folders update through FSEvents. In a remote shell, Boo reuses the connection you already opened.

  • Browse files over SSH, Mosh, docker, podman, kubectl, lima, vagrant, adb and more.
  • Git status shows on files and folders. Ignored files are dimmed.
  • The Git panel lets you stage and unstage files. Switch branches from the status bar.
  • Press / to filter the tree. Rename, trash and multi-select work from the keyboard.

Agents

Boo detects Claude Code, Codex, OpenCode, GitHub Copilot CLI, pi and Hermes in any tab and shows what each one is doing, in every window. It tells you when an agent needs input, can give each task its own git worktree, and lets you review the diff before you merge.

Agent inbox

One list of every agent, colored by state and counted in the status bar. ⇧⌘J jumps to the next agent that waits for input. You get a notification when an agent finishes in a tab you are not looking at.

● needs input ● working ● done ● failed
  • The Agents panel lists sessions, changed files, worktrees, config and skills.
  • ⌥⌘↩ sends the selection or the last command's output to the nearest agent.
  • Agents behind ssh or mosh are tracked too.

Worktree tasks and review

File → New Agent Task… starts an agent on its own boo/<task> branch and worktree. Review the diff, comment on lines, send the comments with ⌘↩, then merge or discard.

Timeline and cost

Step through a Claude Code session: each prompt and tool call with its duration, tokens and cost, and the files it edited.

Orchestrator

⌥⌘O opens a Claude Code session that sees every agent. It can answer waiting agents and split work into parallel tasks. Merges and other risky steps wait for your approval.

Let agents use Boo

Boo ships an MCP server and a boo CLI. With them, an agent can open a pane for the dev server, read test output from another pane, start helpers in their own worktrees and open a review for you.

Command palette

⇧⌘P searches menu commands, workspaces and tabs in every window, bookmarks, SSH hosts, themes, profiles and recipes. Recent picks rank higher.

  • Narrow the search with a prefix: > commands, @ workspaces, @ssh hosts, @op 1Password, @tmux sessions, # tabs, % panes, : themes and profiles, ! history.
  • Highlight a theme to preview it. Esc reverts.

Terminal tools

Shell integration marks every prompt, so Boo knows where each command and its output start and end.

Quick select

⇧⌘Space labels every URL, path, git hash, IP and UUID on screen. Type a label to copy it. Hold ⇧ to paste it at the prompt.

Command blocks

A mark in the gutter for each prompt, red when the command failed. Jump between them with ⌘↑ and ⌘↓. Right-click to copy the output, run it again or send it to an agent.

Copy mode

⇧⌘C puts a keyboard cursor on the scrollback. Move with vi keys, select with v/V, yank with y.

Quick terminal

⌥Space opens a terminal from the top of the screen in any app. Its tabs keep running while it is hidden.

Broadcast input

Type into every pane of a workspace at once, or ⌘-click to pick panes. Panes that run an agent are skipped.

History everywhere

⌃R searches every command you ran in Boo, in all tabs, windows and hosts, with its folder, exit code and duration.

Recording

Record a pane as an asciicast file. Keystrokes are not recorded. Play it back in a tab, or export it as an MP4 in your theme and font.

Write your own plugin

Put a plugin.json and a main.js in ~/.boo/plugins/<name>/. There is no build step. Scripts run in JavaScriptCore, and Boo reloads the plugin when you save.

  • render(ctx) returns stacks, labels, lists, buttons and badges. Colors follow the theme.
  • ctx holds the folder, git state, running process, remote host and the plugin's settings.
  • Actions run commands, paste text, change folder, open tabs or panes, copy and notify.
  • A plugin can add status bar segments, a settings page and menu items with shortcuts.
  • A when clause such as env.local or git.active decides where the panel appears.
Plugin development guide → 
// ~/.boo/plugins/make-targets/plugin.json
{
  "id": "make-targets",
  "name": "Make Targets",
  "version": "1.0.0",
  "icon": "hammer",
  "when": "env.local",
  "runtime": "js",
  "capabilities": { "sidebarTab": true },
  "statusBar": { "position": "left", "template": "make" }
}
// ~/.boo/plugins/make-targets/main.js
function render(ctx) {
  var src = readFile("Makefile");
  if (!src) return { type: "label", text: "No Makefile", style: "muted" };

  var targets = src.split("\n")
    .map(function (l) { return (l.match(/^([a-zA-Z][\w-]*)\s*:/) || [])[1]; })
    .filter(Boolean);

  return {
    type: "list",
    items: targets.map(function (t) {
      return { label: t, icon: "terminal",
               action: { type: "exec", command: "make " + t } };
    })
  };
}

FAQ

How is Boo related to Ghostty?

Boo embeds Ghostty's terminal core through libghostty. Ghostty handles terminal emulation, fonts and Metal rendering; Boo builds the window, workspaces, sidebar, agent tools and everything else around it. Your Ghostty shaders and themes work in Boo.

Which coding agents does it support?

Claude Code, Codex, OpenCode, GitHub Copilot CLI, pi and Hermes are detected out of the box, including when they run behind ssh or mosh. Other AI CLIs show up in the Agents sidebar, and any agent can drive Boo through the MCP server or the boo CLI.

Do I need agents to use Boo?

No. Workspaces, splits, the file explorer, quick select, copy mode, recording, tmux integration and plugins are all useful on their own. The agent features stay out of the way until a terminal runs one.

Does it work on Intel Macs?

Release builds target macOS 15 or later on Apple Silicon. You can try building from source for other setups.

Where does Boo keep my data?

Everything lives in ~/.boo, readable only by you: settings, session, history, notes, recipes, plugins and recordings. Nothing leaves your Mac unless you turn on settings sync to a folder you pick, or remote control on your LAN.

How do updates work?

Boo updates itself through Sparkle. Releases are published on GitHub, so you can also download any version by hand.
