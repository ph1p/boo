# Multi-Content Tabs

A tab is not only a terminal. It can also hold a browser, an editor, an image, a markdown preview, a recording or a plugin view. Tabs of any type can sit side by side in one pane.

## Content Types

| Type              | Shows                                | SF Symbol        |
| ----------------- | ------------------------------------ | ---------------- |
| `terminal`        | Ghostty terminal (default)           | `terminal`       |
| `browser`         | WebKit browser                       | `globe`          |
| `editor`          | Monaco code editor in a `WKWebView`  | `doc.text`       |
| `imageViewer`     | Image preview                        | `photo`          |
| `markdownPreview` | Rendered markdown                    | `doc.richtext`   |
| `castPlayer`      | Terminal recording (`.cast`) player  | `play.rectangle` |
| `pluginView`      | A plugin's SwiftUI view (not saved)  | `puzzlepiece`    |

Agent review and agent timeline tabs are `pluginView` tabs. See [Agents](/agents).

## Opening Tabs

- **File → New Terminal Tab** (⌘T)
- **File → New Browser Tab** (⇧⌘T)
- ⌘-click a URL in a terminal opens a browser tab.
- Opening a file from the file explorer picks the tab type from the file. See [File Opening Settings](#file-opening-settings).

## Plugin API

Open any tab type with `openTab`:

```swift
actions.openTab?(.browser(url: url))
actions.openTab?(.file(path: "/path/to/file.swift"))  // picks the right viewer
actions.openTab?(.customView(title: "My Panel", icon: "star", view: AnyView(MyView())))
```

For a custom tab that should not open twice, register a factory once and open it by ID:

```swift
actions.registerMultiContentTab?("my-diff-view") { ctx in
    AnyView(MyDiffView(context: ctx))
}

let ctx = PluginTabContext(title: "Diff", icon: "doc.badge.plus", key: filePath)
actions.openMultiContentTab?("my-diff-view", ctx)
```

The same type ID and `context.key` focus the open tab in the active workspace instead of opening a new one. See [Plugin Development](/plugin-development).

## Browser

- Swipe to go back and forward.
- The address bar suggests URLs from your history.
- History, link handling and close confirmation live in **Settings → Browser**.

## Editor

The editor is [Monaco](https://microsoft.github.io/monaco-editor/), bundled into the app (`make monaco`) and shown in a `WKWebView`. It follows the Boo theme.

- **Status bar** shows cursor position, indentation, encoding, line endings and language.
- **Save** is ⌘S. **Save As…** is ⇧⌘S. New files ask for a path.
- **Autosave** can be off, after a short delay, or when the editor loses focus.
- **On save** it can trim trailing whitespace, add a final newline and format the file.
- **Reload**: Boo watches the file on disk. A clean buffer reloads. A buffer with edits shows a Reload prompt instead. This can be turned off.
- Files keep their encoding, permissions and symlinks when saved.
- Unreadable or binary files open read-only.

Editor options live in **Settings → Editor**.

File watching uses `WatchedFile` (`Boo/Services/WatchedFile.swift`). It watches the parent directory, so atomic saves (write temp file, then rename) still count. After Boo writes the file it calls `noteOwnWrite()` so its own save does not trigger a reload.

## File Opening Settings

**Settings → Plugins → Files** decides what opens where.

| Setting                  | Values                                                                 |
| ------------------------ | ---------------------------------------------------------------------- |
| Open images as           | `imageViewer` (default), `kitty` (inline in the terminal), `external`  |
| Open text files as       | `editor` (default), `terminalEditor` (`$EDITOR`), `external`           |
| Open markdown files as   | `preview` (default), `builtInEditor`, `editor` (`$EDITOR`), `external` |
| `editorFilePatterns`     | File patterns that open in the built-in editor                         |
| `pdfOpenInBrowser`       | `true` (default): PDFs open in a browser tab                           |
| `htmlOpenInBrowser`      | `false` (default): HTML files open in a browser tab when on            |

Note that for markdown, `editor` means the terminal editor and `builtInEditor` means Monaco.

## Closing Tabs

Boo asks before it closes:

- an editor tab with unsaved changes,
- a browser tab, unless you turned that off in **Settings → Browser**.

Other tabs close at once.

## Architecture

- `TabState.contentType` (`ContentType`) and `TabState.contentState` (`ContentState`) describe a tab. See [Architecture](/architecture#state-model).
- Each non-terminal view conforms to `ContentViewProtocol` (`Boo/Content/ContentView.swift`): `activate`, `deactivate`, `cleanup`, `saveState`, `restoreState` and `save`.
- `ContentViewFactory.createView(for:)` builds the view from a `ContentState`.
- Terminal tabs are the exception. `PaneView.startTerminalSession` hosts a `GhosttyView` directly.
- Plugin views cannot be restored. After a restart they show a "Panel unavailable" placeholder.
