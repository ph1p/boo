# Remote Control

Boo can serve a small web page that controls the terminal from a phone, tablet or second computer on your network.

## Starting the Server

**Terminal → Start Remote Control Server** starts the server on port `8899` and shows a URL like:

```
http://192.168.1.20:8899/#<session-token>
```

Open it on any device in your network. **Terminal → Copy Remote Control URL** copies it again. If the port is in use, Boo shows an error.

While the server runs, the status bar shows an orange **◉ Remote** segment. Click it to copy the URL or stop the server. The menu item then reads **Stop Remote Control Server**.

The server stops by itself after **30 minutes without use**, and a toast says so. A restart creates a new token, so open the new URL.

## What You Can Do

- See the active terminal, in the same colors and layout as the app
- Type text and send keys (arrows, Return, Tab, Esc, ⌃C, ⌃D…)
- Switch workspaces, panes and tabs, and open a new tab
- Answer waiting agents

## Answering Agents

When an agent waits for permission (see [Agent Inbox](/agents#agent-inbox)), a card shows the agent, its workspace and the end of its screen. The page title counts waiting agents, and the phone vibrates on each new request.

- **Approve** presses Return, choosing the prompt's default "Yes".
- **Deny** presses Esc, which cancels the request.
- **Open** brings the agent's tab to the front.

The agent's tab doesn't need to be in front on the Mac. If the agent has asked something new since the card appeared, the answer is refused.

## Add to Home Screen

Use **Share → Add to Home Screen** (iOS) or **Install app** (Android) while the `#token` URL is open. The page then gets its own icon and a full-screen window. Add it again after the server restarts, since the token changes.

## Security

- Every request must carry the session token. Requests without it are rejected.
- The token is new on every start and sits in the URL fragment (`#…`), which browsers never send over the network.

:::warning
Anyone with the URL can control your terminal. Treat it like a password and stop the server when you're done.

The connection is **plain HTTP**. Anyone on the same network can read the token and the terminal in transit. Use Remote Control only on a network you trust, never on public Wi-Fi.
:::
