# Features

## Workspaces

Open folders as workspaces with their own file tree using **Cmd+Shift+N** (home directory) or **Cmd+Shift+O** (choose folder). Each workspace maintains its own state, color, and name.

- **Workspace colors** — Assign preset or custom colors per workspace
- **Pinning** — Pin frequently used workspaces
- **Renaming** — Double-click a workspace pill to rename it, or use the right-click context menu
- **Session persistence** — Workspace names, colors, split layouts, tab paths, and split pane ratios are saved to `~/.boo/session.json` and restored on next launch. Remote connections are not restored; tabs reopen at their local working directory.
- **Drag to switch workspace** — While dragging a tab, hover over a workspace pill for ~500 ms to spring-load into that workspace, then drop the tab onto any pane there.

## Split Panes

Split your terminal in any direction:

- **Cmd+D** — Split right
- **Cmd+Shift+D** — Split down
- **Cmd+]** / **Cmd+[** — Focus next / previous pane
- **Cmd+Opt+Arrows** — Select the pane in that direction
- **Cmd+Ctrl+Arrows** / **Cmd+Ctrl+Shift+Arrows** — Resize / swap panes
- **Cmd+Shift+Return** — Zoom the active pane; **Cmd+Ctrl+=** — equalize splits

Each split pane is independent with its own tab bar and terminal sessions. Drag the divider between panes to resize, or drag a tab onto a pane edge to split; ratios are saved and restored across launches.

## Multiple Windows

**Cmd+N** opens a new window. Drag a tab out of the window to tear it off, move a workspace with **Window → Move Workspace to New Window** (or the workspace context menu), or bring everything back with **Window → Merge All Windows**. All windows are restored on next launch.

See [Windows & Splits](/windows-and-splits) for the full guide.

## Per-Pane Tabs

Each pane has its own tab bar. Create new terminal tabs with **Cmd+T** (browser tabs with **Cmd+Shift+T**), close with **Cmd+W**, and switch with **Cmd+Opt+1-9** or **Cmd+Shift+1-9**. Closed tabs can be reopened with **Cmd+Opt+Z**. Tabs can also host a browser, text editor, image viewer, or markdown preview — see [Multi-Content Tabs](/multi-content-tabs).

Smart close order: tab → pane → workspace.

- **Right-click a tab** — Context menu with "Close Tab" (or "Close Workspace" when it's the only tab) and a "Move Tab to Workspace →" submenu listing all other open workspaces.
- **Drag tabs across workspaces** — Drag a tab to a different pane or split zone in the current workspace, or use the workspace pill hover to move it to another workspace entirely. Moving the last tab out of a workspace prompts to close that workspace.

## File Explorer

Toggle the sidebar with **Cmd+B**. The explorer shows a live-updating file tree for the current workspace.

- **Local workspaces** — Uses FSEvents for real-time file system watching
- **Remote SSH / Mosh** — Auto-detects SSH-style sessions and reuses shared connections for file listing when possible
- **Remote containers / VMs / devices** — Auto-detects interactive `docker`, `podman`, `nerdctl`, `kubectl`, `oc`, `lxc`, `limactl`, `colima`, `distrobox`, `toolbox`, `vagrant`, and `adb shell` sessions and runs the appropriate listing command for each tool

**Local explorer:**

- **Multi-select** — **Cmd+click** toggles, **Shift+click** / **Shift+↑↓** extends a range
- **Keyboard navigation** — Arrows, **Return** to open, **F2** rename, **Cmd+Delete** to Trash, type-ahead to jump (see [shortcuts](/keyboard-shortcuts#file-explorer))
- **Filter bar** — Fuzzy-filter the whole tree; press **/** to focus it
- **Git status** — VS Code–style badges (M, A, D, R, U, !) on files, rolled up to folders; git-ignored files are dimmed

**File click behavior** (local files):

- **Text/code files** matching the editor file patterns — Built-in editor tab (`textOpenMode`; can also run your terminal editor or open externally)
- **Images** — Image viewer tab (`imageOpenMode`; or inline via the Kitty Graphics Protocol, or the default macOS app)
- **Markdown** — Rendered preview tab (`markdownOpenMode`; or editor, terminal editor, or external app)
- **PDF** — Browser tab (`pdfOpenInBrowser`, on by default)
- **HTML** — Browser tab when `htmlOpenInBrowser` is enabled (off by default)
- **Other files** — Opens with the default macOS app

Configure all of this in **Settings → Plugins → Files**. See [Multi-Content Tabs](/multi-content-tabs#file-explorer-settings).

## Sidebar Plugins

The sidebar shows stacked, collapsible panels powered by the [plugin system](/plugins):

- **Files** — Live file tree for the current directory. Supports local (FSEvents) and remote (SSH, Mosh, containers, VMs, and device shells) browsing. Click to open, right-click for context menu.
- **Git** — Branch name, staged/unstaged/untracked files, ahead/behind. Inline stage/unstage buttons. Refresh on file system changes.
- **Agents** — Agent Center for Claude Code, Codex, and OpenCode: open sessions, config, and diffs. **Show Timeline** replays a Claude Code session: prompts, tool calls, tokens, cost and edited files.
- **Snippets** — Saved code snippets with syntax highlighting and quick insertion.
- **Docker** — Running containers with exec, logs, start/stop/restart. Live updates via `docker events` stream. Local sessions only.
- **Bookmarks** — Saved directory shortcuts with per-host namespacing for remote sessions.
- **System** — CPU, memory, disk, network, load, uptime and battery, with quick `df -h` / `top` / `netstat` / `uptime` actions. Optional status bar readouts.
- **Debug** — Live log of plugin lifecycle events and current terminal state, for plugin authors.

Toggle panels via status bar icons or extend with [custom plugins](/plugin-development).

## Agents

Boo tracks coding agents running in your terminals across all windows:

- **Agent inbox** — See which agents are working or waiting; **Cmd+Shift+J** jumps to the next waiting one
- **Agent tasks** — **File → New Agent Task…** starts an agent in its own git worktree
- **Review mode** — **File → Review Changes…** opens a diff tab where you comment on lines and send feedback back (**Cmd+Return**)
- **Handoff** — **Cmd+Opt+Return** sends the terminal selection or last command output to the nearest agent
- **Timeline** — **File → Agent Timeline** replays a session with tokens and estimated cost
- **Remote approve** — Approve or deny waiting agents from the [remote control](/remote-control) page

See [Agents](/agents) for the full guide.

## MCP Server

`Boo --mcp` runs a stdio [MCP](https://modelcontextprotocol.io) server that lets agents read the pane layout, split panes, read or type into other panes, list agents, start agent tasks and open reviews. See [Agents](/agents).

## Git Integration

The status bar shows the current git branch name. Click it to open a branch switcher showing both local and remote branches. The Git sidebar panel shows changed files with inline stage/unstage actions.

## Status Bar

Configurable segments displayed at the bottom of the window:

- **Environment** — Colored dot + label showing the active environment (`local`, `ssh`, `mosh`, `docker`, `kubectl`, and other supported remote types)
- **Git branch** — Current branch name with switcher popup
- **Path** — Current working directory
- **Running process** — Foreground process (zsh, node, vim, etc.)
- **Plugin icons** — Toggle icons for Files, Git, Docker, Bookmarks panels
- **Pane count** — Number of active panes and tabs
- **Clock** — Current time

Toggle individual segments in **Settings → Status Bar**, including path visibility and git branch display.

| **Status Bar**    | Toggle individual segments (connection, path, git branch, process, pane count, clock)              |
| **Layout**        | Sidebar position (toggle with Cmd+B), workspace bar position, tab overflow mode                    |
| **Editor**        | Built-in text editor preferences                                                                   |
| **Browser**       | Browser tab history and behavior                                                                   |
| **Notifications** | Notification preferences                                                                           |
| **Plugins**       | Enable/disable plugins, per-plugin settings (file explorer icons/hidden files, git settings)       |
| **Shortcuts**     | Searchable keyboard shortcut reference                                                             |
