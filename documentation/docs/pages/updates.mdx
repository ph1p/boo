# Updates

Boo updates itself with [Sparkle](https://sparkle-project.org/).

## Checking

- Sparkle checks for updates in the background.
- **Boo → Check for Updates...** checks right away.
- The update feed is `https://ph1p.github.io/boo/updates/appcast.xml`. Release archives come from [GitHub Releases](https://github.com/ph1p/boo/releases).
- `make run` builds never check: the debug bundle has no `SUFeedURL` or `SUPublicEDKey`.

## Installing

When you install an update, Boo:

1. Downloads the release archive.
2. Checks its Sparkle EdDSA signature and its code signature.
3. Replaces the app and relaunches.

Releases signed with the same certificate keep your [permissions](/installation#permissions).

## Releases

[semantic-release](https://github.com/semantic-release/semantic-release) cuts releases from conventional commits on `main`. CI builds and signs the app, publishes the ZIP to GitHub Releases, and deploys the new appcast to GitHub Pages. The appcast is not committed to the repository; docs-only deploys keep the published one.
