# Keyboard Shortcuts

**Settings → Shortcuts** lists every menu command, with or without a shortcut, and has a filter.

**Rebinding**: click a shortcut and press the new keys. A shortcut needs ⌘, ⌃ or ⌥, or an F key. Delete removes it, Esc cancels, and the ↩ button restores the default. If another command already uses the keys, that command loses them and the page says which. Changes are saved in `~/.boo/settings.json` (`shortcutOverrides`) and sync with your other settings.

The tables below list the defaults.

## File Explorer

When the file tree has focus:

| Shortcut                        | Action                                              |
| ------------------------------- | --------------------------------------------------- |
| **Up** / **Down**               | Move selection (**Shift** extends it)               |
| **Right** / **Left**            | Expand / collapse folder, or go to parent           |
| **Return**                      | Open file or toggle folder (first match while filtering) |
| **Esc**                         | Clear filter, then selection                        |
| **Cmd+Delete**                  | Move to Trash                                       |
| **F2**                          | Rename                                              |
| **/**                           | Focus filter bar (when shown)                       |
| Type letters                    | Jump to matching name                               |
| **Cmd+click** / **Shift+click** | Toggle / extend selection                           |

With the navigation bar shown, **Opt+Up** goes to the parent folder, **Opt+Down** opens the selected folder, **Opt+Left** / **Opt+Right** go back / forward, and **Delete** goes up.

## Key Tables

Key tables add tmux-style leader keys. They are off until you create `~/.boo/keytables.json`:

```json
{
  "leader": "ctrl+a",
  "timeout": 2,
  "tables": {
    "root": {
      "v": "Terminal/Split Right",
      "s": "Terminal/Split Down",
      "z": "Terminal/Zoom Pane",
      "k": "send:kubectl get pods\n",
      "w": { "table": "window" }
    },
    "window": {
      "n": "Window/Merge All Windows"
    }
  }
}
```

Press the leader, then a key from `root`. The status bar shows the mode (**⌃A …**, or **⌃A → window** in a chained table). A value is one of:

- a menu command, as its menu path joined with `/` (`Terminal/Broadcast Input to/All Panes in Workspace`)
- `send:<text>`, which types text into the terminal
- `{ "table": "<name>" }`, which waits for a key from another table

Esc, an unbound key, or `timeout` seconds (default 2) end the mode. Pressing the leader twice types the leader itself.

Write keys as `v`, `V` (or `shift+v`), `ctrl+w` or `cmd+opt+left`. Named keys are `escape`, `tab`, `return`, `space`, `backspace` and the arrows. When Boo becomes active, it reloads a changed file and lists unknown commands, tables or keys in one alert.
