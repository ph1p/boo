# Plugin System

Plugins fill the sidebar and the status bar. Each plugin gets its own sidebar tab, and some also add a status bar segment.

There are two kinds:

1. **Built-in** — Swift classes in `Boo/Plugins/`, compiled into the app.
2. **External** — JavaScript in `~/.boo/plugins/<name>/`, loaded at runtime. Save a file and the plugin reloads.

To write your own, see [Plugin Development](/plugin-development).

## Built-in Plugins

| Plugin         | ID                                    | Shown when                       | Description                                                  |
| -------------- | ------------------------------------- | -------------------------------- | ------------------------------------------------------------ |
| **Files**      | `file-tree-local`, `file-tree-remote` | local / SSH or Mosh              | File explorer: local (FSEvents) and remote browsing          |
| **Git**        | `git-panel`                           | local git repo                   | Branch, staged/unstaged/untracked files, ahead/behind        |
| **Agents**     | `agents`                              | local                            | Agent Center for Claude Code, Codex, OpenCode and other AI CLIs |
| **Docker**     | `docker`                              | local                            | Containers with exec, logs, start/stop/restart               |
| **Bookmarks**  | `bookmarks`                           | always                           | Saved directories, namespaced per host                       |
| **Hosts**      | `hosts`                               | always                           | `Host` entries from `~/.ssh/config`; click to connect        |
| **Kubernetes** | `kube`                                | always (**off by default**)      | Pods, workloads, jobs, services and ingresses                |
| **Notes**      | `notes`                               | always                           | Markdown note per workspace, saved to `~/.boo/notes`         |
| **Snippets**   | `snippets`                            | always                           | Saved commands to paste into the terminal                    |
| **System**     | `system-info`                         | local                            | CPU, memory, disk, battery; optional status bar readouts     |
| **Debug**      | `debug`                               | always                           | Live plugin event log and terminal state, for plugin authors |

Git, Docker, Bookmarks, Hosts and Kubernetes hide while an AI agent (Claude Code, Codex, …) runs in the focused pane. Agents, Docker, Git, System and Debug also add a status bar segment.

## Enabling and Configuring

**Settings → Plugins** turns each plugin on or off and shows its settings. Kubernetes starts disabled; enable it there. The Agents plugin has its own settings page.

## How It Works

Each terminal state change runs one **plugin cycle**. Triggers: pane focus, working directory, title, foreground process, remote session start/end, and workspace switch.

1. **Enrich** — plugins add shared data (e.g. git status).
2. **Freeze** — the data becomes an immutable `TerminalContext` snapshot.
3. **React** — plugins read the snapshot.
4. **Evaluate** — each plugin's `when` clause decides whether it is visible.
5. **Rebuild** — the sidebar and status bar update.

A cycle should finish in under 16 ms. Boo logs a warning when one takes longer. Plugins whose data changes in the background (Docker events, a git commit) request a new cycle themselves.

## Plugins Menu

Plugins can add items to the **Plugins** menu in the menu bar, with optional keyboard shortcuts. Shortcuts that clash with built-in ones are skipped.
