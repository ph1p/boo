# Getting Started

See [Installation](/installation) to download or build Boo.

## First Launch

1. Open Boo. It starts with a workspace in your home folder, and the **Welcome to Boo** window lets you pick a theme. Reopen it with **Help → Welcome to Boo**.
2. **Cmd+Shift+O** opens a folder as a workspace.
3. **Cmd+B** shows or hides the sidebar.
4. **Cmd+D** / **Cmd+Shift+D** split the pane right / down.
5. **Cmd+Shift+P** opens the command palette.
6. **Cmd+,** opens Settings.

## Key Concepts

- **Workspaces** are folders, each with its own color and state
- **Panes** are splits inside a workspace, each with its own tab bar
- **Tabs** live inside a pane. Most are terminals, but a tab can also hold a browser, editor, image viewer or markdown preview ([Multi-Content Tabs](/multi-content-tabs))
- **Windows** each hold their own workspaces; **Cmd+N** opens a new one
- **Sidebar** shows plugins (files, git, agents, hosts, notes and more) for the active tab

**Cmd+W** closes the tab, then the pane, then the workspace.
