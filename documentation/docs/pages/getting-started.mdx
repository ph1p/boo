# Getting Started

See [Installation](/installation) for download and build instructions.

## First Launch

1. Open Boo — it starts with a workspace in your home directory, and the **Welcome to Boo** window lets you pick a theme and shows a few key shortcuts (reopen it with **Help → Welcome to Boo**)
2. **Cmd+Shift+O** to open a project folder as a workspace
3. **Cmd+B** to toggle the sidebar file explorer
4. **Cmd+D** / **Cmd+Shift+D** to split panes
5. **Cmd+,** to open settings and pick a theme

## Key Concepts

- **Workspaces** are project folders, each with its own color and state
- **Panes** are split views within a workspace, each with its own tab bar
- **Tabs** live inside a pane — usually terminals, but a tab can also host a browser, text editor, image viewer, or markdown preview ([Multi-Content Tabs](/multi-content-tabs))
- **Windows** each hold their own workspaces; **Cmd+N** opens a new one
- **Sidebar** shows plugins (files, git, agents, snippets, docker, bookmarks, system info, debug) for the active tab

Close order is smart: **Cmd+W** closes tab → pane → workspace.
