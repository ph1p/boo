# Windows & Splits

Each window has its own workspaces, sidebar and plugins. Settings, themes and bookmarks are shared. Inside a workspace, panes split the terminal area, and each pane has its own tabs.

## Windows

| Action             | Shortcut / Menu                                                                                    |
| ------------------ | -------------------------------------------------------------------------------------------------- |
| New window         | ⌘N (**File → New Window**)                                                                         |
| New workspace      | ⇧⌘N (**File → New Workspace**)                                                                     |
| Move workspace out | **Window → Move Workspace to New Window**, or **Move to New Window** in a workspace's context menu |
| Merge windows      | **Window → Merge All Windows**                                                                     |

**Merge All Windows** moves every workspace into the current window and closes the others. Pinned workspaces, and a window's only workspace, can't be moved out.

### Dragging between windows

- **Workspaces**: drag a workspace pill onto another window to move it there. Drop it outside any window to open it in a new window.
- **Tabs**: drag a tab onto a pane in another window to move it. Drop it outside every window to open it in a new window.
- Hover a workspace pill for half a second to switch to it, then drop.
- A window left without workspaces closes. Moving a workspace's last tab asks first.

### Session restore

On quit, Boo saves every window with its workspaces, frame, full-screen state and sidebar. On launch they all come back. Windows whose folders no longer exist are dropped.

## Splits

| Action                     | Shortcut   | Menu                                      |
| -------------------------- | ---------- | ----------------------------------------- |
| Split right                | ⌘D         | **Terminal → Split Right**                |
| Split down                 | ⇧⌘D        | **Terminal → Split Down**                 |
| Select pane in a direction | ⌥⌘ arrows  | **Terminal → Select Pane**                |
| Next / previous pane       | ⌘] / ⌘[    | **Terminal → Focus Next / Previous Pane** |
| Resize pane                | ⌃⌘ arrows  | **Terminal → Resize Pane**                |
| Move (swap) pane           | ⌃⇧⌘ arrows | **Terminal → Move Pane**                  |
| Zoom pane                  | ⇧⌘↩        | **Terminal → Zoom Pane**                  |
| Equalize splits            | ⌃⌘=        | **Terminal → Equalize Splits**            |
| Close pane                 | ⇧⌘W        | **File → Close Pane**                     |

The arrow shortcuts match Ghostty's defaults. Resize moves the divider 10 points per step. Move swaps the pane with its neighbor, and focus follows.

**Zoom** fills the workspace with the active pane. While zoomed, an unzoom button sits in the pane's bottom-right corner. Click it or press ⇧⌘↩ again to show all panes. Selecting a hidden pane also ends zoom.

### Drag to split

| Drop target                  | Result                                         |
| ---------------------------- | ---------------------------------------------- |
| Tab bar                      | Inserts the tab there                          |
| Middle of a pane             | Adds the tab to that pane                      |
| Edge of a pane               | Splits that pane; the tab becomes the new pane |
| Outer edge of the workspace  | New pane along that whole side                 |
| Middle of a pane, holding ⌥  | Swaps the two panes                            |

A pane left without tabs closes.

## tmux

Run `tmux -CC` (or `tmux -CC attach`) and Boo shows the session natively: each tmux window becomes a workspace, and each tmux pane a Boo pane. Splits and new tabs in such a workspace go through tmux. Quitting Boo leaves the tmux session running.

Turn it off with **Settings → General → Native tmux windows**. The change applies to terminals opened afterwards.
