# Installation

## Download

Boo needs macOS 15 (Sequoia) or later on Apple Silicon.

1. Download `Boo-x.x.x.zip` from [GitHub Releases](https://github.com/ph1p/boo/releases)
2. Unzip it
3. Move **Boo.app** to **Applications**
4. Open Boo

:::note
If macOS says Boo cannot be opened, run:

```bash
xattr -dr com.apple.quarantine /Applications/Boo.app
```
:::

Boo checks for updates on its own. See [Updates](/updates).

## Permissions

**Settings → Permissions** shows who signed the running app and whether Boo has Full Disk Access. It has **Open…** buttons for the Full Disk Access, Files and Folders, Developer Tools and Automation panes of System Settings.

Programs you run in Boo inherit its grants. Giving Boo Full Disk Access stops the folder prompts from shells and tools. A grant applies to programs started after it.

Releases keep the same signature, so macOS keeps your grants across updates.

## Build from Source

**Prerequisites:** Xcode 26 / Swift 6.2 (or the Command Line Tools), Zig 0.17.0 (`brew install zig`), Rust (`rustup`), Node.js + pnpm, and the Metal Toolchain (`xcodebuild -downloadComponent MetalToolchain`).

```bash
git clone --recursive https://github.com/ph1p/boo.git
cd boo
make setup    # Builds GhosttyKit, ironmark, Monaco and Boo
make run      # Build and launch
```

If you cloned without `--recursive`, run `git submodule update --init --depth 1`.

The first build takes a few minutes. Later builds are cached.

`make run` builds a debug app with Sparkle turned off, so it never checks the release update feed.

### Keep permissions across builds

A plain build is signed ad hoc, and that signature changes every build. macOS then forgets Boo's privacy grants and asks again. Create a stable signing identity once:

```bash
scripts/create-signing-cert.sh
```

It adds a self-signed **Boo Self-Signed** certificate to your login keychain. `make run` signs with it whenever it is there. Keep `~/.boo/signing` backed up: a new certificate resets the grants once.

### Release build and tests

```bash
make app      # Optimized .app bundle
make zip      # Distributable ZIP
make dmg      # Distributable DMG
make test     # Run the tests
```

Release bundles keep the Sparkle feed settings from `Boo/App/Info.plist`.

## Uninstall

1. Quit Boo
2. Delete `Boo.app` from Applications
3. Optionally remove your settings and data: `rm -rf ~/.boo`
